# Day 3 — AI vs ML vs DL

Today I learned the relationship between **Artificial Intelligence (AI), Machine Learning (ML), and Deep Learning (DL).**

The correct hierarchy is:

```text
Artificial Intelligence (AI)
            ↓
    Machine Learning (ML)
            ↓
      Deep Learning (DL)
```

## 1. Artificial Intelligence (AI)

**AI** is the broad field of creating machines or systems that can perform tasks that normally require human intelligence.

### Examples

- Chatbots
- Self-driving cars
- Voice assistants
- Game-playing systems
- Recommendation systems

**Example:**  
A system that can understand a person's voice and respond intelligently can be considered an AI system.

---

## 2. Machine Learning (ML)

**Machine Learning is a subset of AI.**

ML allows computers to **learn patterns from data and make predictions or decisions without explicitly programming every rule.**

### Example

Suppose we have house data:

```text
Area       Price
800 sq.ft  ₹40 lakh
1200 sq.ft ₹60 lakh
1800 sq.ft ₹90 lakh
```

The ML model learns the relationship between **area and price**.

When we provide a new house:

```text
Area = 1500 sq.ft
```

The model can predict its price.

### Other examples

- Spam email detection
- House price prediction
- Customer churn prediction
- Fraud detection

---

## 3. Deep Learning (DL)

**Deep Learning is a subset of Machine Learning.**

Deep Learning uses **artificial neural networks with multiple layers** to learn complex patterns from large amounts of data.

### Examples

- Face recognition
- Speech recognition
- Image classification
- Self-driving cars
- Generative AI

### Example

A deep learning model can learn to recognize whether an image contains a:

```text
🐱 Cat
or
🐶 Dog
```

It can learn complex patterns such as shapes, edges, textures, and other visual features from images.

---

## AI vs ML vs DL

| AI | ML | DL |
|---|---|---|
| Broadest concept | Subset of AI | Subset of ML |
| Makes machines perform intelligent tasks | Learns patterns from data | Uses deep neural networks |
| Can use rules, ML, or other techniques | Requires data for learning | Usually benefits from large amounts of data |
| Example: intelligent assistant | Example: spam detection | Example: face recognition |

## Simple Real-World Example

Imagine a **self-driving car**:

**AI:** The overall goal is to make the car behave intelligently.

**ML:** The car can learn patterns from driving data to predict things such as whether an object is a pedestrian.

**DL:** A deep neural network can process camera images and recognize pedestrians, vehicles, traffic signs, etc.

## Key Takeaway

```text
AI
└── ML
    └── DL
```

> **AI is the broader field, ML is a subset of AI, and DL is a subset of ML.**

### What I learned today

I learned that AI, ML, and DL are not three completely separate fields. They are related in a hierarchy:

**AI → ML → DL**

AI is the broadest concept, Machine Learning allows systems to learn from data, and Deep Learning uses multi-layer neural networks to learn complex patterns.
