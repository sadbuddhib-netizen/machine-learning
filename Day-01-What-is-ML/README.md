# Day 1 — What is Machine Learning?

## What I learned

Machine Learning is a branch of AI where computers learn
patterns from data and use those patterns to make
predictions or decisions.

## Traditional Programming

Rules + Data → Output

## Machine Learning

Data + Output → Learning/Model

## Why do we need Machine Learning?

Machine learning is useful when it is difficult to
write explicit rules for every possible situation.

## Real-world examples

- Spam detection
- Recommendation systems
- Image classification
- Fraud detection

## My understanding

ML allows a computer to learn patterns from existing data
and use those patterns on new/unseen data.
